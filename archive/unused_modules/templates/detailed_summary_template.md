## Quality Standards

This template ensures detailed summaries include:

✅ **Technical Implementation Details**:
- Full code blocks with inline comments
- Actual configuration files (not descriptions)
- Complete command sequences with all flags
- File paths and directory structures
- Environment variables and their purposes

✅ **Step-by-Step Guides**:
- Prerequisites clearly listed
- Numbered steps with explanations
- Expected outputs at each step
- Troubleshooting for common issues

✅ **Real-World Context**:
- Use cases and when to apply
- Cost implications and optimizations
- Performance metrics and benchmarks
- Security considerations

✅ **Code Quality**:
- Syntax highlighting for language
- Inline comments explaining WHY, not just WHAT
- Before/after examples for comparisons
- Anti-patterns clearly marked

❌ **Avoid**:
- High-level descriptions without implementation
- "You can configure X" without showing HOW
- Partial code snippets missing context
- Generic advice without specific examples
